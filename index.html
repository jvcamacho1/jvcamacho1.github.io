Sobre

Pipelines escaláveis, entregues como código

Sou Engenheiro de Computação pela UTFPR e trabalho com dados desde 2022. Minha experiência inclui projetar, implementar e otimizar pipelines de dados, com base sólida em Big Data (Hadoop, PySpark, Hive) e no ecossistema AWS (Glue, Athena, S3, Lambda, Step Functions, Kinesis), além de bancos relacionais e não relacionais.

Hoje, na GFT, implanto pipelines batch e streaming com Terraform e GitHub Actions e ajudo a transformar dados de dezenas de contas AWS em produtos num Data Mesh. Antes, na TCS, migrei rotinas legadas de SQL Server e SAS para Hadoop e, depois, para AWS Glue.

Fora do trabalho, construo o Órbita Notícias, um pipeline de notícias que opero em produção de ponta a ponta, da ingestão ao serving.

Órbita Notícias

Comparador de cobertura jornalística. Coleta as manchetes de 42 veículos de todo o espectro político, detecta quais tratam do mesmo acontecimento e mostra, lado a lado, como cada um enquadrou o fato. Projetei, construí e opero o sistema de ponta a ponta.

42fontes ingeridas
5 minintervalo de ingestão
15 minintervalo de reagrupamento
1.130testes automatizados
48 hjanela de comparação
100%precision no corpus rotulado
1 GBservidor de produção
7workflows no GitHub Actions

Destaques de engenharia de dados

  • Ingestão resiliente: RSS com fallback automático para o sitemap de notícias quando o feed congela sem aviso; log de falhas por fonte em JSONL; workflow diário de saúde dos feeds.
  • Migrações de schema como comando: versionadas, com trava e backup antes de cada execução; um script de backfill reconstrói eventos antigos.
  • Camada de serving pré-computada: a etapa pesada (TF-IDF + agrupamento) roda só no worker; a camada web lê um cache pronto e continua no ar se o worker cair.
  • Qualidade medida: corpus rotulado de 192 manchetes, precision/recall/F1 por par e um teste que reprova se a métrica cair abaixo da linha de base.
  • CI/CD: lint, testes, auditoria de dependências, deploy com health check e rollback automático.
